## Deliberate differences

- TypeAlias exposes only fields supported by its schema. Annotation/record/basic-type and other declarations without a dedicated editing form use shared read-only inspection rather than pretending to be editable.
- Function output metadata uses `['output']`. Its existing public structural API edits the output type; this change does not invent output-name/cardinality actions.
- Canonical synonym variants remain different domain payloads. Their interaction and factories are shared; they are not coerced into a parallel common AST.
- Temporary invalid or stale rich edits fail field validation/guards. The editor retains the draft and does not report a successful source write. Scope changes use the existing transition barrier.
- Authored comments stay in Source. The serializer preserves their text/ownership after structural edits; internal comments may move around their regenerated construct. Untouched declarations and expression bodies remain byte-identical.
- The two reference-path grammar interfaces are explicit because inferred left-recursive actions incorrectly made a DataReference inherit AttributeReference while schemas rejected nested receivers. Grammar, AST, domain operations and both Zod surfaces were regenerated with repository scripts; the wire node names and Rune path syntax remain the same.
