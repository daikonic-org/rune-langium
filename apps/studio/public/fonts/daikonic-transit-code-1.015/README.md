# Daikonic Transit Code

Code 1.015, from the approved `transit-arrows-2026-11-14/Code` release supplied
with the Daikonic Transit font project. The unmodified variable WOFF2 spans
weights 300–400; Studio's CodeMirror editors use Book 350. Other monospace UI
continues to use JetBrains Mono.

SHA-256 (`DaikonicTransitCode600-VF.woff2`):
`8322d17650a185d38cc75a59be8ca394f4b1894a8d4ffa952dd399d61dede45e`

The bundled font retains its upstream SIL Open Font License in [OFL.txt](OFL.txt)
and attribution in [NOTICE.txt](NOTICE.txt). The WOFF2 lives in `src/assets/fonts` and Vite fingerprints it in Studio's
static assets. This versioned public directory ships its license and notice.
The editor needs no external font service.
