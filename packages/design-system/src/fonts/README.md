# Daikonic Transit webfonts

Unmodified WOFF2 files from [Daikonic Transit](https://github.com/daikonic-org/transit-typeface):

| Family | Version | Use |
| --- | --- | --- |
| Sans | 0.109 | Headings, wordmark and display text |
| System | 0.117 | UI and body; automatic optical sizing, 10–36 |
| Code | 1.025 preview | CodeMirror, Book 350 |

See [manifest.json](manifest.json) for release links, exact file checksums and
variable-axis ranges. Code 1.025 is the latest published preview imported here;
the unpublished 1.026 draft is not included. JetBrains Mono remains the general
monospace token. Faces use `font-display: swap` and load only when used.

Fonts retain the [SIL Open Font License](OFL.txt) and [upstream notices](NOTICE.txt).
These files ship together in the package and the combined site's `fonts/` directory.
