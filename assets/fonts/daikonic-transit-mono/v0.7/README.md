# Daikonic Transit Mono v0.7

Experimental Johnston-inspired monospaced typeface, normalized using JetBrains Mono's glyph-width-to-cell ratios.

## Download

[DaikonicTransitMono-v0.7.zip](./DaikonicTransitMono-v0.7.zip) — includes installable TTF and WOFF2, editable UFO and SVG source, code proofs, and width benchmarks.

The typeface remains a design trial; complex shapes and all-platform code-editor behavior have not received a full optical validation.
